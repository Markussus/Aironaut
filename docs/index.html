AIRONAUT ESP32-S3

Waveshare ESP32-S3 Touch LCD 3.5 • Raumluft-Messgerät

Verbinde deinen Aironaut per USB-C (Datenleitung) mit dem PC und klicke in Google Chrome oder Microsoft Edge auf Install.

Nach dem Flashen:
1. Beim allerersten Start wird die interne Partition (LittleFS) formatiert – das dauert einige Sekunden.
2. Das Gerät startet immer den eigenen Hotspot Aironaut-AP (Web-Dashboard unter http://192.168.4.1/).
3. Heim-WLAN kannst du direkt am Touch-Display unter Einstellungen → WLAN → Netzwerke suchen einrichten.

Falls kein COM/USB-Port reagiert:
BOOT-Taste gedrückt halten, kurz RESET drücken, BOOT loslassen und Installation erneut starten.
